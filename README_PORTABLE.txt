GLINT REMOTE VIEWER - portable Windows x64

Run:        double-click GlintRemote-Viewer.cmd (keep it inside this folder: it needs runtime\).
            A black window may flash for a moment: that's normal.
Install:    not needed. Move the whole folder wherever you like.
Uninstall:  delete this folder, and optionally %APPDATA%\GlintRemote (settings only, no credentials).
If Windows asks "Do you want to run this file?", choose "Run". It works with Smart App Control on:
            runtime\ is the official, digitally signed Python runtime, unmodified.
Usage:      type your friend's Twitch channel name (or paste a YouTube live link) and press Connect.
            F11 = fullscreen, M = mute, Up/Down = volume.
Full guides: GUIDE_VIEWER.md and GUIDE_BROADCASTER.md on the project's GitHub page.
